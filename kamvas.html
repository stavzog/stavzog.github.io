PROJECT OVERVIEW

Project Kamvas was inspired by the Mercury OS concept and it allows you to arrange dynamic modules (Markdown, Code, Web, and more) side by side on an infinite canvas. It is currently in an MVP Stage.

Project Kamvas allows users to plan and build by composing custom workflows. Click the "+" button to compose yours.

STATE MANAGEMENT

Project Kamvas was built with Kotlin Multiplatform and follows OOP principles. I also rolled out a custom state management solution. It integrates concepts from Zustand which is known for its simplicity and ease of use.

Unidirectional State Flow

State flow is unidirectional and it is based on the Model-View-Intent (MVI) approach.

Immutable State Objects

Module state is stored as immutable data classes and actions (command like "update text") produce new state objects.

Extensibility (Open/Closed Principle)

New module types, actions, and renderers can be added without modifying the core ModuleViewModel or the main ModuleView Composable.

Handcrafted DI

Dependency management is explicit via constructor injection and a central DependencyContainer.

The idea guiding all architecture decisions was that the code should have minimal bloat and no external library "magic".

NEXT STEPS
