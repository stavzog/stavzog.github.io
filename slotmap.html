PROJECT OVERVIEW

A tiny Rust slot manager for stable handles and packed data. It tracks identity and dense indices, while leaving data ownership and memory layout to your application.

WHY SEPARATE THE MANAGER?

The manager owns the mapping, not the payload. When an item is removed, it supplies the dense indices needed to swap the last entry into the gap. The user's code applies that swap to each array.

A handle combines a slot and generation. The slot can be reused, while the generation makes an old handle stale instead of accidentally pointing to the new item.

USED IN PARAMETRIC EMBROIDERY

Nodes and user guide points use handles as stable IDs. Their numeric data stays in packed buffers, so the frontend can refer to an entity without relying on a dense index that may change.
