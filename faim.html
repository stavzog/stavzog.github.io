OVERVIEW

At Faim Lab, I contributed automated tests and frontend refactoring to GISST. The Game and Interactive Software Scholarship Toolkit (GISST) is a web-based tool for citing and retrieving recorded software performances and saved states.

TEST THE USER FLOW

I added Playwright tests that interact with the player and verify the resulting UI state:

  • Saving a state adds an entry to the saved-states list.
  • Starting and finishing a performance adds a replay to the replay list.

In the frontend embed, I decoupled GISST URL parsing and configuration fetching from the player setup. This made it straightforward to test URL formats and server error responses with Vitest, without initializing the emulator UI.

TECHNOLOGIES

Playwright · Vitest · TypeScript
